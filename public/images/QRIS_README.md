# QRIS Placeholder

Tambahkan gambar QRIS Anda di sini dengan nama `qris-placeholder.png`

## Cara mendapatkan QRIS:
1. Buka aplikasi e-wallet (Dana/OVO/GoPay/ShopeePay)
2. Buat QRIS merchant atau QRIS personal
3. Screenshot atau download gambar QRIS
4. Simpan di folder ini dengan nama sesuai database
